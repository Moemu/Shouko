# 果蝇具身项目开发参考

最近核查：2026-09-21，调查过程见 [研究记录](reviews/2026-09-21.md)。对象：X 上 **@satorunet** 的 hae 与 **@yakshawan** 的 FFREP，以及与其实现直接相关的研究资料。

本目录整理这两个公开项目的进展、实现与可核实的边界：各自走到哪一步、代码如何组织、哪些成绩可以直接引用、哪些问题还没有公开材料。任何社区成员都可以用它做对照与借鉴；文中引用按固定版本给出，原始文件可从公开地址取回并逐文件核对哈希。

## 为什么关注这两个项目

本项目的主线是把真实果蝇连接组当作控制网络来驱动身体。下面两个项目探索的是同一个大问题的不同分支，并且都公开了可查证的材料：

- **hae**：把 FlyWire 脑连接组做成浏览器里运行的脉冲神经仿真（WASM），用识字、人体角色、算盘、LIFE 等任务分别演示一种能力；源码与在线页面公开。
- **FFREP**：用 MaleCNS 连接组分别驱动 SHOKI 四足与 YUMEKA 人形身体；目前公开的是 FAQ 与训练过程视频。

它们涉及本项目同样会遇到的问题：脉冲计算如何压缩进浏览器、可塑连接如何只训练局部、工程步态与神经控制如何分工、演示成绩怎样才能被复核。本目录把这些内容整理成笔记、对照表与固定版本引用。

说明资料性质：本目录是外部资料整理与候选验证问题的汇总；某项结论是否被本项目采纳，仍按 [AGENTS.md](../../../AGENTS.md) 的提案、对比与用户定稿流程决定。

## 名词入门

本节面向不熟悉神经仿真与控制术语的读者，每条一句话；往下读遇到这些名词时可按需回查。已有相关背景的读者可以直接使用上面的入口。

**神经与连接组**

| 名词 | 含义 |
|---|---|
| 连接组（connectome） | 描述神经元之间连接关系的数据集：谁连谁、接触多少次。它记录结构，不含功能强弱；本项目与 hae 都以连接组作为控制网络的骨架。 |
| KC / MBON / DAN / DN | 蘑菇体通路里的四类神经元：KC（肯扬细胞，稀疏编码输入）、MBON（蘑菇体输出神经元）、DAN（多巴胺能神经元，传递奖励 / 惩罚类调制信号）、DN（下行神经元，把脑信号送向运动系统）。 |
| VNC | 腹神经索，位于脑下方；FlyWire 脑图与 MaleCNS 对它的覆盖范围不同。 |
| LIF（漏积分发放） | 常用的脉冲神经元模型：膜电位持续累积，越过阈值发放一次，然后重置并进入短暂不应期。hae 的仿真核心即 LIF。 |
| 活动率模型 | 本项目的神经计算方式：每个神经元是一个连续活动值，每次决策迭代 4 次，不含脉冲时间；与 LIF 的状态、时间与梯度语义都不同。 |
| 静默（silencing） | 在某个任务中关闭指定神经元的活动，用于限定参与计算的范围；hae 的不同任务有不同静默名单。 |
| 可塑增益 | 连接权重上的可训练倍率，只施加在指定连接子集上。 |

**学习与评估**

| 名词 | 含义 |
|---|---|
| 局部可塑性 / 三因子规则 | 只用突触前后活动与一个调制信号（如多巴胺）更新连接，不对整个网络做反向传播；hae 的识字任务用它训练 KC→MBON 读出。 |
| 人工脑叶（Blank Lobe） | FFREP 在连接组之外附加的 1,024 神经元模块；其结构、训练范围与消融结果未公开。 |
| 消融（ablation） | 移除系统的一部分再测行为，用来判断该部分是否真的在起作用；本项目页面上的「断开脑内连接」即一种消融。 |
| 留出（held-out） | 不参与调参的场景或数据，用于独立检验成绩；本项目评估使用固定的初态与种子。 |

**身体与仿真**

| 名词 | 含义 |
|---|---|
| IK（逆运动学） | 由手或脚的目标位置反解出各关节的角度。 |
| 工程步态 / 静态步态 | 预先设计的行走轨迹或姿态序列，由控制器执行，并不来自网络学习。 |
| PD 控制 | 用力矩 = 位置误差 × P + 速度误差 × D 把关节拉向目标角度；本项目用它把网络输出变成关节力矩。 |
| 根外力 / 根力矩 | 仿真可直接施加在躯干上的辅助力。hae 的公开代码把它们设为 0，同时使用支撑与平衡求解及额外关节力矩。 |
| WASM | 浏览器可直接执行的编译产物；hae 用它把 C 写的神经仿真搬到网页里运行。 |

## 资料等级

本目录的每条结论都来自以下五类材料之一，正文中按级别标注：

- **源码核查**：本次读到相关代码或配置；它证明的是实现内容。
- **作者报告**：原帖、FAQ、README 或论文中的说法；本次未独立复跑。
- **本地实测记录**：本项目 `runs/` 中已有的评估输出；与检查点哈希绑定，来自既有实验。
- **推断 / 候选**：资料整理者的分析，尚未经过验证。
- **未知**：现有资料不足以判断的问题，正文中不作推测。

## 引用与使用说明

1. **三种来源各自独立**：固定 Git 版本、在线部署与作者文字在版本、内容与许可上可能不同；本目录按来源分别标注。
2. **版本一致按来源分级**：固定提交的内容可精确核对，哈希应始终一致，不一致属于异常；在线部署与上游分支会随上游更新，再次取回与采集日不同属于正常更新——记录新日期与哈希、注明引用的是哪一份即可，上游仍然可以继续参考。
3. **本仓库只分发分析、链接与校验元数据**，上游源码与媒体不随仓库分发；取回方法与逐文件哈希见 [来源、许可与取回](COLLECTION.md)。
4. **许可按来源判断**：hae 在固定提交声明 MIT，文件级与第三方条款仍需核对；FFREP 未取得重分发依据；在线部署字节的许可覆盖未核实。本目录的中文整理不改变任何第三方许可，也不代表作者背书。
5. **本次没有执行上游代码**，也未变更本项目模型；工作范围见 [证据、版本与复现边界](VERIFICATION.md)。
6. **证据缺口与反例是两回事**：缺少公开评估不说明任务失败，缺少代码不说明实现不存在；未取得的部分在正文中标为「未知」。
7. **「最近核查」日期指核查时间**，与内容的发布日期无关；后续变化追加到 [reviews/](reviews/)，并注明来源与新旧版本。
