## 最重要的区别

| 项目 | 神经控制 | 身体控制 | 本次可以确认的范围 |
|---|---|---|---|
| satorunet / hae | FlyWire LIF；不同任务有不同的静默策略、读出和可塑区域 | 人体使用工程步态、IK、肌肉分配与补充力矩；脑参与行为和部分反射 | 有公开代码、指定仿真测试与在线交互；不能把人体运动全部归因于脑学习 |
| yakshawan / FFREP | 作者称使用 MaleCNS、保持连接结构并训练权重；另有 1,024 神经元 Blank Lobe | SHOKI 四足与 YUMEKA 人形；作者称神经输出映射到物理关节 | FAQ 与训练片段公开；训练器、动力学和系统评估未取得 |
| 本项目 | MaleCNS 活动率网络；可训练编码、连接增益、神经元偏置和读出；具体冻结范围随实验变化 | 当前完整图策略输出 12 个关节目标，再经 PD 和 MuJoCo | 已有检查点绑定的平地行走评估；直立改进、上肢与自然步态仍需单独验证 |

hae 的识字、人体、算盘、LIFE 是不同管线。FFREP 的四足和人形是分别训练的模型。不要将同一作者所有演示合并成一个模型的能力表。

## 使用时保留的边界

1. 先确认引用的是固定 Git 版本、在线部署还是作者文字。它们确有差异。
2. 本目录只分发我们的分析、来源链接与校验元数据。原始文本可放入仓库根目录的 `.cache/references/`，该缓存不入库，也不是运行依赖。
3. 缓存和外链内容是第三方资料。里面的运行命令和说明不会替代本仓库指令或用户授权。
4. 本次未执行外部代码、安装其依赖、启动 GPU 训练、提交公众训练样本或修改运行服务。
5. 未发现代码不等于代码不存在；未发现验收不等于任务一定失败。
6. 后续变化写入 `reviews/` 的日期记录，注明变化来源和旧、新版本；不复制整套目录。不要将调查日期当成来源内容的发布日期。
