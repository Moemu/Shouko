# 证据、版本与复现边界

本页说明这批资料是怎么核实的：完成了哪些核查、来源之间有哪些差异、公开声明各自覆盖到什么范围、完整复现还缺什么。结论的引用分级（源码核查 / 作者报告 / 本地实测 / 推断 / 未知）见 [入口页说明](README.md#资料等级)。一句话概括：本目录没有运行任何上游代码，所有外部结论都按上述级别标注。

## 1. 本次核查的范围

已完成的工作：

- 阅读 X 上的相关公开帖子；网页直接抓取受限时改用浏览器查看。
- 通过 GitHub API 固定两个仓库的版本，下载所选文本文件并计算 SHA-256。
- 定点阅读关键仿真、控制、学习、筛选与迁移源码（逐文件阅读程度见 [源码索引](SOURCE_INDEX.md)）。
- 单独获取 hae 在线部署的部分文本源文件，记录内容类型与哈希。
- 读取本项目已有 Yumi 评估、实验编年与 CPU 修正交接。
- 整理固定版本引用、检索索引、论文入口与候选验证问题。

未做的工作：独立复现两位作者的训练、性能或生物结论；未启动本项目的新训练，也未改变已有模型。

## 3. 测试文件的覆盖面

hae 的 [`flybrain/test/det.mjs`](https://github.com/satorunet/hae/blob/d4551c26cab1c029b2628dbfaca563fbd2e7bc3d/flybrain/test/det.mjs) 写出脉冲事件；运行时需要输出路径参数，文件注释还指向 Brian2 一侧的比较程序。只运行这个文件并看到事件输出，与完成跨实现一致性检查是两件事。

`validate.mjs`、`det2.mjs`、`learn.mjs` 的用途值得参考；复现前需要先确认它们依赖的图、参考结果、参数、运行版本与判定方式。本目录没有运行它们，也没有确认所有外部参考文件都已完整发布。

FFREP 仓库中的网页测试只检查 FAQ 网站的构建，与控制器训练效果无关。

## 5. 本项目的比较基准

[local-evidence.json](local-evidence.json) 摘录自 [runs/local/heldout_yumi.json](../../../runs/local/heldout_yumi.json)，保存源文件 SHA-256（`0c7d5e7a…`）、检查点 SHA-256（`a7a4281f…`）、图 SHA-256（`72a6a9ad…`）与选定结果。

记录内容：9/9 平地测试、3/3 侧推测试、120 秒行走 65.55 米（横向漂移 0.13 米）；三个断连对照均在约 1 秒内跌倒。数字来自该既有记录，适用范围限于其中的场景、初态与检查点，不代表其它扰动、地形或身体配置。

后续直立世系与 50 维实验另有检查点与配置；ppo17 的噪声筛选问题见 [编年](../../experiments/PPO_OBS50_20260920.md)，2026-09-21 的接口与筛选修正见 [交接](../../LOCAL_FIXES_20260921.md)。交接中的 CPU 检查不是新的完整图 GPU 行走验收。

## 6. 复现前需要补齐的材料

### hae

- 选择固定 Git 版本，或已配套齐全的在线发布版本。
- 图文件、注释、静默名单、WASM 与构建工具版本。
- 可塑区域布局、权重来源、身体配置与配置迁移历史。
- MyoSim 身体与派生改动、MuJoCo 版本、贴图或角色许可。
- 仿真测试的参考输出与比较程序。
- 具身测试的初态、随机种子、噪声、成功标准、同步方式与重复次数。

### FFREP

- 训练器与神经动力学实现；输入输出及完整图筛选规则。
- 身体模型、物理引擎与动作接口；人工辅助和教师使用说明。
- Blank Lobe 的结构、连接、训练范围与消融。
- 权重、配置、训练预算和留出场景原始结果。
- 实现、数据与资产的可用许可。

以上是核对本次材料后整理的缺口清单；补齐它们需要向作者取得更多公开材料，或在公开信息基础上自行重建。

## 7. 本目录的更新方式

- 变化按日期记录在 `reviews/` 中，写明旧 / 新版本和受影响的结论；旧来源记录与基线清单保持原样，不复制全量源码或清单。
- 新取的文件重新计算 SHA-256；内容变化时不沿用旧哈希。
- 证据等级的上调以前确认的远程提交、路径与用途为前提：先核实，再改写「未知」或「作者报告」。
- 新的实验数字引用 `runs/` 的原始文件与检查点，不从演示视频估算成绩。
- 本目录尚未执行上游代码；若后续真的完成复现，在新研究记录中写明过程与结果。
