未独立复现两位作者的训练、性能或生物结论。未启动本项目的新训练或改变已有模型。

## 3. 测试文件不等于复现通过

hae 的 `flybrain/test/det.mjs` 写出脉冲事件；它需要输出路径参数，文件注释还指向 Brian2 侧比较程序。只运行这个文件并看到事件，不等于完成跨实现一致性检查。

`validate.mjs`、`det2.mjs`、`learn.mjs` 的用途值得参考，但在复现前需检查它们依赖的图、参考结果、参数、运行版本和判定方式。本目录没有运行它们，也没有确认所有外部参考文件都已完整发布。

同理，FFREP 仓库中的网页测试只检查 FAQ 网站，不能证明控制器的训练效果。

## 4. 不可互换的成绩

| 声明 | 不能据此推出 |
|---|---|
| 指定 LIF 测试与 Brian2 一致 | 恢复了真实果蝇全部生理或行为 |
| 识字测试准确率提高 | 全脑自由行为或人体行走同步提高 |
| 四肢着地爬到食物 | 完成自然双足行走 |
| 探索噪声下动作丰富 | 确定性策略学到了相同动作 |
| 新增人工脑叶后表现改善 | 原始连接组有同等能力 |
| 断连后失败 | 连接组优于同预算重训的随机图 |
| 裁剪后某组测试一致 | 任意未见刺激下都一致 |
| 身体没有根部外力支撑 | 没有工程步态、辅助关节力矩或平衡求解器 |
| 页面等级上升 | 留出场景成绩上升 |

## 5. 本项目的比较基准

[local-evidence.json](local-evidence.json)是从 `runs/local/heldout_yumi.json` 提取的摘要，保存原文件 SHA-256、checkpoint、图标识及选定结果。源文件绑定 `a7a4281f604c82831bf947fe599d490dd5d223bf479c9c44289e7b4d76508d97`。

该记录包含 9/9 平地测试、3/3 侧推测试和约 65.55 米的 120 秒行走。三个断连测试均跌倒。所有数字来自该原始记录，不是此次训练或复跑结果，也不能推广到所有扰动和地形。

后续直立世系与 50 维实验另有检查点和配置。ppo17 的噪声筛选问题见 [编年](../../experiments/PPO_OBS50_20260920.md)；2026-09-21 的接口与筛选修正见 [交接](../../LOCAL_FIXES_20260921.md)。交接中的 CPU 检查不构成新的完整图 GPU 行走验收。

## 7. 本目录更新方式

1. 在 `reviews/` 中按日期记录变化、旧/新版本和受影响结论，保留旧来源记录；不复制全量源码或清单。
2. 新取文件重新计算 SHA-256；如内容变化，不沿用旧哈希。
3. 确认远程引用的 commit、路径和用途，再升级“未知”或“作者报告”的证据等级。
4. 新实验数字引用 `runs/` 的原始文件与 checkpoint，不从演示视频估算成绩。
5. 引用本目录时保留“不曾执行”的状态，直到真的完成复现并写出结果。
