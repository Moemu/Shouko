# ZCode：横漂机制分解与方向控制三层路线（独立提案）

日期：2026-09-26。**独立性声明**：本提案只依据用户转述的 Codex 本轮结论（继续、不重构核心、方向控制优先、两分支 120 秒横漂 5.47/4.90 m、显式相位保留）、`research/experiments/` 编年、`app/` 源码与 `runs/` 实测文件写成，未阅读 `research/proposals/` 下任何提案正文。关键论断逐条附出处；推断单独标注。未实际运行任何新仿真，本提案中新的数值结论均来自对既有产物文件的离线重算。

## 1. 实测事实与机制判读

### 1.1 成果边界（无争议部分）

两分支四组留出严格通过且零跌倒：主候选 `ridge1e4/last.pt`（140001 普通 27/27、141001 偏航 18/18、142001 长走 9/9、143001 推扰 9/9），独立分支 `extra1/last.pt`（240001–243001 对应 27/27、18/18、9/9、9/9）。来源 `runs/connectome_transfer_replica_20260923/final_summary.json`（两检查点 SHA-256 与编年一致）。相对固定来源仅 `readout.weight/bias` 改变（815 输出 × 12 动作 + 12 偏置 = 9,792 参数；`data/full_graph.json` output_neurons=815，`app/full_brain.py:64`），断连 0/9、重复轨迹哈希一致、native CSR 27/27（`runs/connectome_transfer_ridge_20260923/lesion.json`、`native_csr.json`）。

但方向指标全部不合格：主候选精确 yaw 恢复 7/27（普通）、9/18（偏航）、1/9（长走）；独立分支 0/27、6/18、1/9；长走横漂 5.473451 m 与 4.896459 m（同上 final_summary.json）。

### 1.2 核心新论断：横漂主体是身体坐标系侧滑（斜行），不是航向误差

对主候选开发代表轨迹（seed 103002、0.5 m/s、30 s；`runs/connectome_transfer_ridge_20260923/candidate_trace.npz`）做离线分解：终点 |y| = 0.879 m，其中按 0.8 s 滑窗平滑后积分，航向项 ∫v·sin(yaw) 贡献 −0.024 m（约 2.8%），身体坐标系侧滑项贡献 −0.821 m（约 97%）；平滑未覆盖的高频残差 <0.04 m。平均侧滑速度约 −0.032 m/s（前向速度的约 6%），而平滑 yaw 均值仅 −0.0017 rad。

该结论可从留出汇总直接算术复核（推断，算术推导）：航向驱动的横漂上界为 v·mean|yaw|·t。142001 长走组 mean|yaw| 为 0.027–0.029（`runs/connectome_transfer_ridge_20260923/long_holdout.json`），则 0.35 档航向项 ≤ 0.35×0.027×120 ≈ 1.13 m，远小于实测 8.2 m；0.5 档 ≤1.74 m（实测约 4.05 m）、0.65 档 ≤2.28 m（实测约 4.2 m）。三档均侧滑主导。0.35 档实测侧滑约 0.068 m/s，为前向速度的 19.6%，且 8.215 m 距方向判据容许值 `max(1, seconds·speed·0.2)` = 8.4 m（`app/evaluate_locomotion.py:136`）仅 0.19 m——当前 0.35 档的"通过"是贴线通过，lambda=0.001 版本正是在这一档失败（同种子 115001 对照 6/9 对 9/9，编年《正则对照开发通过及严格配对补充》节）。

### 1.3 精确朝向失败 = 步态锁相摆动卡在门槛内

代表轨迹 raw yaw 标准差 0.037、范围 [−0.087, +0.077] rad，FFT 主周期 0.789/0.811 s，与显式步态周期 0.8 s（physics_interface `gait_period_s: 0.8`）一致。精确恢复门槛 |yaw|≤0.05 rad 连续 0.5 s（`app/evaluate_locomotion.py:60-64`）恰好卡在摆动幅度 ±0.08 rad 之内——多数回合永远进不满 0.5 s。旁证（推断，算术巧合级）：30 s 回合 finalYaw 为 +0.0588～+0.0787（120 s = 150 个完整步态周期，30 s = 37.5 个，恰差半个周期），120 s 回合 finalYaw 翻号为 −0.0776～−0.0849，与"锁相摆动在不同时刻采样"的预测一致。推扰组精确恢复反而 9/9（两分支皆是，final_summary.json），因为推扰瞬态把系统踢入恢复段后才落回稳态，恢复段内 |yaw| 有更长时间低于 0.05。

### 1.4 侧向控制权限存在：trim 是学到的吸引子，不是执行器极限

推扰留出（+0.25 m/s 侧向速度脉冲 @10 s）净横漂仅 0.027–0.430 m（均值 0.277 m），显著小于无扰动组的 0.86–1.83 m（`runs/connectome_transfer_ridge_20260923/push_holdout.json` 对 `holdout.json`）。若不加修正，该脉冲本身在剩余 20 s 内就会积累约 5 m。这说明闭环能把侧向速度扰动拉回**同一个漂移 trim**（约 −0.03～−0.07 m/s）——侧向速度环增益足够，缺的只是"trim 应为零"这一条，而这是标签问题。

### 1.5 因果链：教师奖励扁平 → 教师 trim → 标签继承 → 学生 trim

1. 教师 PPO 训练时 vy 命令恒为零：`app/ppo_yumi.py:303-304` 仅设置 `command[:,0]`，yaw 命令用与评估相同的 `clip(-yaw*1.4, ±0.2)` 弱 P 律（`app/ppo_yumi.py:335`）。
2. 教师奖励对精度量级无压力（`app/ppo_yumi.py:353-355`）：vy 项 `0.6·exp(−6·vy²)` 反解 σ≈0.29 m/s，yaw 项 `0.8·exp(−3·yaw²)` 反解 σ≈0.41 rad；在实测 trim（0.03–0.07 m/s、0.08 rad）下每步损失 ≤约 0.02（量级计算，推断），相对总奖励 ~3.5 可忽略。教师自身留出即为证：120 s 横漂 4.847 m、精确恢复仅 1/18（`research/experiments/ROUTE_EXECUTION_20260923.md` 教师留出表）。
3. 迁移全部训练数据（教师回合与各轮 DAgger 同一采集函数）使用 `[v, 0, clip(-yaw*1.4, ±0.2)]`（`runs/connectome_transfer_20260923/imitation_dagger_source.py:47`），标签忠实继承教师 trim。
4. 学生复现教师量级：教师同条件长走均值 4.83868 m（`runs/connectome_transfer_ridge_20260923/teacher_matched_long.json`），独立分支学生 4.896459 m，主候选 5.473451 m。两条独立数据拟合的读出与教师同向同量级漂移，支持 trim 来自教师而非拟合偶然（推断）。

### 1.6 对两个既有"意外"的机制解释（推断，可检验）

- **三个 alpha 折中点全败**：原读出与扰动读出都编码同一 trim，线性插值不产生"直线"这一新行为，只在新旧行为间过渡；方向改善需要不同标签，不是读出混合。
- **方向跨阶段退化**（dagger3 留出长走 4.46002 m → push2 122001 6/9、5.93662 m → ridge1e4 5.473451 m，编年）：推扰 DAgger 数据把状态分布推向"扰动后恢复"区域，与直线 trim 的覆盖互相挤占；lambda=0.0001 之所以有效，是低收缩更好地拟合了既有数据中方向相关的弱信号，但没有新增"直线"标签。

## 2. 与 Codex 建议（用户转述）的异同

**同意**：继续当前路线、暂不重构连接组核心；下一阶段优先方向控制。但我的理由不同：不是"核心已被证明够用"，而是现有全部失败模式都能定位在读出之外的三层（教师奖励、标签命令律、验收命令律），没有任何一条证据指向核心容量——断连对照证明参与、lambda 对照解释了正则、alpha 失败有了机制解读。重构核心在当前证据下没有靶点。

**分歧/补充四点**：

1. "精确方向控制"应拆成三个可分别验收的子问题：侧滑 trim（横漂主项，97%）、步态锁相 yaw 摆动（精确恢复主项）、命令律本身（现有 P 律增益 1.4、限幅 ±0.2，只反馈 yaw 不反馈侧滑）。合并成一句"方向控制"会掩盖"提高 yaw 增益对横漂几乎无效"这一设计推论（航向本来就近零）。
2. 纯克隆的标签上界是教师。要在不动核心的前提下超越教师的 4.85 m，必须改标签（校正命令下的 DAgger）或改教师（奖励精化后重跑迁移）。建议把这一点写进预注册，防止 Phase 1 成功后被表述成"连接组自身习得方向控制"。
3. 0.35 档 8.215/8.4 m 是贴线通过。方向控制验收必须换更严的新门槛重新过，不能沿用现判据宣布"方向已解决"。
4. 显式相位问题有一个便宜的实验路径（Phase 3 的相位盲 DAgger），不必停留在"保留但未证明"的表述。

## 3. 路线提案（供用户定稿）

### Phase 0：机制定标（不训练，约半天，本地或云端均可）

- **0.1 逐档分解**：用 `record_candidate.py` 同型脚本对固定候选录 120 s × 3 速度档全序列轨迹，逐档复核 1.2 的侧滑/航向分解与 trim 数值。0.35 档目前只有算术推断，需要直接证据。
- **0.2 命令响应探针**：教师（`runs/yumi_route_20260923/support_refine2027/last.pt`，SHA-256 `9c5ca933…`，不覆盖）与学生（`ridge1e4/last.pt`）在 103001 开发初态下分别喂 vy 命令 ∈ {0, ±0.05, ±0.1, ±0.2} 与加强型 wy 律（更高增益、加角速度阻尼），测实现的 vy/yaw 响应曲线。同时测常数偏置补偿（vy_cmd = +|trim|）与闭环反馈两种校正形式。此探针直接决定 Phase 1 是否可行：若教师对 vy 命令无响应，跳过 Phase 1 直入 Phase 2。
- **0.3 相位依赖消融**：对固定候选把观测第 45:47 维（sin/cos 相位，`app/sim.py:146-152`）替换为常数后在 103001 验收。注意现有 `--zero-new` 消融的是 47:50（世界系速度+高度，`app/evaluate_locomotion.py:101`），**相位消融从未在最终候选上运行过**（各 JSON 仅 normal/repeat/lesion 条件）。

### Phase 1：读出-only 方向再拟合（主臂，沿用冻结核心与既有管线）

- 校正命令律（0.2 探针选型）注入采集：学生执行、教师打标签的 DAgger 轮次不变，仅命令流改为 `[v, vy_corr, wy_strong]`；特征缓存按新观测重算，ridge=0.0001 与既定配置不变，仅拟合 readout。每轮采集+拟合墙钟参照上一轮实测约 48.6 s + 44.0 s（编年《独立分支》节），加开发验收预计单轮分钟级。
- 开发门槛沿用 103001/114001/115001 三组既有门槛，另加**预注册新方向档**（建议值，待用户定稿）：115001 每速度档终点横漂 ≤ max(2 m, seconds·speed·0.05)（即 0.35 档 ≤2.1 m、0.5 档 ≤3.0 m、0.65 档 ≤3.9 m），推扰与长走同过且跌倒 ≤1。精确恢复继续报告但建议本轮不设门槛（其主因是摆动幅度，属教师侧问题）。
- 通过后用未占用种子段做四组留出（建议 150001/151001/152001/153001 与独立分支 250001 段；编年内未出现该段，预注册前需再核对一次），并复核断连、native CSR 与重复哈希。
- **判读边界**：验收对象是"冻结核心 + 读出 + 校正命令律"组合；命令律参数必须像 `physics_interface` 一样写入验收文件。通过不得表述为"连接组习得方向控制"。
- 保留推扰数据与全部历史轮次（extra1 已证明学生失败态覆盖的价值：9 个低速回合在原学生下约 12.5 s 跌倒，编年）；若学生拉直后推扰门槛失守，按既定判别加轮，不重演 alpha 式折中。

### Phase 2：教师方向精化（条件臂，仅当 0.2 探针判 Phase 1 不可行或 Phase 1 未过门槛）

- 从 `support_refine2027` 配对状态续训，单变量收紧两个扁平高斯（建议先 vy 项 σ 0.29→约 0.10 m/s，yaw 项第二步再动），不覆盖原权重，原成绩永久保留。
- 教师达到横漂 ≤2 m/120 s 且精确恢复改善后，重跑既有迁移管线（五阶段脚本与审计链齐全，上一轮全流程约 74 分钟可作为吞吐参照）。
- 这会更换教师、重置来源链：新链 SHA 全程重固定，旧链只读保留。

### Phase 3：相位盲 DAgger（并行小臂，成本与一轮 DAgger 相当）

- 教师 retains 相位输入照常打标签；学生观测中相位两维置常数后执行与学习。若学生在开发门槛内行走，即给出"冻结核心动力学 + 本体反馈可承载节律"的第一手证据，把"显式相位保留"从表述问题变成实验结论；失败则量化相位依赖（与 0.3 互相印证），且不证明"自主节律不可达"，只限定当前管线。
- 该臂不与生物拓扑优势声明挂钩。

### 明确不做（范围纪律）

不重构核心、不重开全图 PPO（恢复课程两种子失败记录仍在）、不细搜 alpha 连续区间（三预定点失败已够）、不在本轮改身体/观测接口/步态周期。发现的旧账单列：REPORT.md 描述的仍是 8,192 子图旧管线，与当前 166,700 全图管线并存易误导，建议后续单独更新（本提案不动它）。
