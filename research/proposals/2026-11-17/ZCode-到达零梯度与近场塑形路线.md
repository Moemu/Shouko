# 到达零梯度与近场塑形路线

日期：2026-11-17。独立提案（主代理自稿）。

来源与独立性声明：本文基于 [局部因子编年](../../experiments/LOCAL_GOAL_FACTORIAL_20261116.md)、`runs/local_goal_factorial_20261116/screen/`（`analysis.json`、`braking_diagnostic.json`）与 `app/goal_task.py`、`app/gpu_goal.py`、`app/local_goal.py`、`app/ppo_goal.py` 的自行核对重算。**未读其他 2026-11-17 提案正文**；完成机制分析后查阅了 [proposals README](../README.md) 的索引摘要，其中"制动探针先行"与本文探针臂方向重合，索引另披露一处本文未复核的工程观察（Codex：保存 rollout 无结束步），见末节披露。所有数字与代码论断均为自行重算，不引用其他提案结论。

## 一句话现状

四组 0/3 通过；策略学到了"向目标位移"（iid_zero 最小距离 0.088 米）和"少做功/冻结"（persistent_cost 第 2 秒后毫米级静止），但**训练历史到达次数为 0**：任务用来定义"成功"的那部分奖励，在全部 2,695,168 次已更新转换中一次也没有出现，从未产生过梯度。策略优化的是替代目标，而替代目标的最优解（快冲、越过、冻结）与任务成功（减速、停留）不重合。

## 自行重算的证据

数字出自 `screen/analysis.json`、`screen/braking_diagnostic.json` 与编年；代码行号出自当前工作区。

- **E1 成功项零观测**。12 个 run 的 `training_arrivals` 全为 0；九份最终确定性策略仅 iid_zero/1402 入圆（0.087650 米），最近点速度 0.940 m/s，半径内最小速度 0.463 m/s，`max_dwell_fraction` 为 0。奖励中的到达项 `+1`（`app/local_goal.py:164`）从未被采样轨迹兑现，GAE 中不存在任何来自它的优势。
- **E2 dwell 是全有全无的 50 步连续事件**。`dwell_limit = ceil(1.0/0.02) = 50`（`app/gpu_goal.py:91`）；每步只有在圆内且水平速度 ≤0.2 m/s 才累进 1，否则清零（`app/gpu_goal.py:209`）。观测里已经包含 dwell_fraction（`app/goal_task.py` OBSERVATION_FIELDS），但奖励 = progress + 到达 − 0.001×功，**没有任何近场项**：从未到达的轨迹上，减速和停留行为没有任何中间奖励可学。
- **E3 稠密塑形偏好早位移，后退惩罚被折扣**。progress = d_t − d_{t+1}，γ=0.99、回合 250 步（推断：越过目标后的后退步集中在回合末段，折扣后代价小；0.99^250≈0.08）。x 轨迹形态与此一致：iid_zero/1401 在 3→4 秒穿过目标 x 线（相对原点 1.97→2.81 米）但侧偏约 0.48 米，最近 0.45 米；1402 入圆（x 峰 2.11 米）后弹回 0.84 米；1403 接近后回撤（1.65→0.32 米）。三份末段全部远离目标 −1.04～−1.35 米。
- **E4 功成本惩罚的是"噪声做功"而非"低效位移"**。iid_cost 的 base std 从 0.70 收到 0.575–0.581，功 3.6–5.2 J，净进展 ≤0.87 mm（冻结在原点）；iid_zero std 保持 0.700–0.705，功 6.5–11.8 kJ，位移 0.29–0.72 米。persistent_cost 学到"扑一次然后冻结"：x 在第 2 秒后毫米级不动（0.175/0.178/0.175）。随机扑腾不产生净位移时，成本项唯一可学方向就是少动。
- **E5 持续零功是最能发现运动的格子，也是唯一被警戒线删掉的格子**。3/3 于 6.7 万–17.3 万转换时穿透 31.3–31.9 mm 中止。代码推导：持续分布逐步噪声 std = base_std×sqrt(1−rho²)（`app/local_goal.py:86`）≈0.31（iid_zero 为 0.70），但中心按 rho=0.9 平滑、时间常数约 0.2 秒（`app/local_goal.py:85`），低频连贯推动既产生位移也产生贴地穿透。均值策略评估也已到 22 mm（iid_zero/1402）——30 mm 线与倒伏贴地推进的接触深度天然接近。
- **E6 固定单初态 + 固定 +x 方向**。每回合同一状态同一目标，开环"猛扑"是合法局部最优，与持续推进门（1–5 秒 ≥0.20、3–5 秒 ≥0.05）要求的重复再加速矛盾。

## 机制判断

四个可分离的失败机制，本轮 2×2 的任何一个臂都没有针对它们：

1. **M1 成功事件不可观测**（E1+E2）：到达与 50 步连续 dwell 在训练中从未发生，奖励的学习信号退化为"稠密 progress − 功"。
2. **M2 近场无塑形**（E2）：制动与停留没有任何中间奖励；dwell_fraction 已在观测里，却未被奖励利用。
3. **M3 成本与发现耦合**（E4）：位移未发现之前，功成本只会教"少动"；成本轴（效率）在发现轴解决之前不可归因。
4. **M4 探索幅度与穿透警戒线冲突**（E5）：最需要发现运动的探索恰好越线。这不是警戒线错了，是探索结构本身不安全。

## 路线（预登记候选，待用户定稿）

| 臂 | 内容 | 判定门 | 回答 |
|---|---|---|---|
| D（零训练，最先） | D1 目标重定向：现成 iid_zero 权重，评估时把目标改到 −x 或 1 米，看轨迹是否重定向（闭环/开环判定）。D2 物理制动：零训练脚本让倒伏身体获得约 0.9 m/s 前向速度后动作置 0/置 home，测水平速度 0.94→0.2 m/s 所需时间与位移 | D2 若 PD 置零下 1 秒内减不到 0.2 m/s，停留门的物理可行性存疑，A/B/C 全部重新设计 | 给 A–C 划边界 |
| A（近场塑形，单因素） | 任务语义全部不动（半径 0.3、速度上限 0.2、停留 1 s、到达 +1、边界），只加近场项。两个子臂：A1 dwell 累进塑形——合格步每步 +k_dwell，满额 ≤0.5（塑形只在合格步累进、出圆或超速清零，满额 50 步时到达本身触发，无悬停刷分通道）；A2 半径内超速惩罚 −k_speed×max(0, v−0.2)。基座用 iid_zero 同种子同预算复跑，已完成的三个 iid_zero run 直接作对照 | 训练内到达 >0（对照为 0）、半径内最小速度下降、max_dwell_fraction >0 | M1/M2 |
| C（探索-警戒线相容） | 持续组探索幅度收进安全域：动作截断从 ±8 收到预登记扫描 ±2/±4/±6（或 base std 上限下调），persistent_zero 复跑 | 3/3 完成 262,144 转换、零中止，且任一种子 min_dist <0.5 米（运动发现保留）；若安全域内无法发现运动 → 物理-探索冲突确认，交回停机门第 3 条 | M4 |
| B（成本课程，最后） | cost 组 work_cost 从 0 起步，净进展 ≥0.25 米里程碑后按预登记步进升到 0.001 | cost 组达到 zero 组位移水平后收敛到低功 | M3 |

优先序与依赖：D 零成本先做；A 用 iid_zero 基座，不依赖 C；C 与 A 可并行；B 只有在运动发现解决后才有意义。若 A+C 组合仍训练内零到达，则现有奖励/探索框架对该任务不足，进入身体/任务接口的路线讨论（停机门第 3 条）。

主判据说明：不看探针或单点行为，而看**"训练内到达次数从 0 变为 >0"**——这是唯一能直接证明 M1（成功事件不可观测是根因）的指标。近场塑形若有效，应同时表现为半径内最小速度向 0.2 m/s 以下移动。
