## 结论

保留用户已经选定的 **50 维观测 + 直立世系**，先补齐验收接口和实验诊断，再做一次有预算上限的小型对照。现在不建议继续延长固定价值损失门控，也不建议直接宣布价值网合格后长时间开训策略。

## 2. 我不同意的几个推断

### 2.1 高价值损失不能直接证明优势信号不可用

`app/ppo_yumi.py` 的 `v_loss` 是回报目标与价值预测的均方误差。奖励整体乘以 c，价值及回报同步乘以 c 时，MSE 会乘以 c²；归一化后的拟合质量却可以不变。因此跨奖励配方比较“历史 10、现在 100”，不能直接判定训练失败。

30 次或 300 次更新未过人为门槛，只能说明**该实现与预算下没有达到这个门槛**。它没有区分目标漂移、优化不足、模型容量、不可观测状态、回报噪声或诊断错误，更不能证明存在不可约损失下限。

反过来，反对这个门槛也不等于价值网已经足够好。应记录同一批样本、同一时刻的回报目标方差、MSE、偏差和解释方差，并检查小幅策略更新的实际效果。

### 2.2 最新诊断不能支持“价值网已解释 80–97% 方差”

`runs/yumi_obs50/diagnose_value.py` 至少有以下口径问题：

- 第 36 行先裁剪 `log_std`，之后才指数化。配置 std=0.08 时，实际用成约 1.051；正确次序是 `log_std.exp().clamp(...)`。这已经是另一个探索分布。
- 第 73 行在两次 rollout 结束后求 `v0`，却与第一次 rollout 起点的累计回报比较，状态与时刻不对应。
- 跌倒后重置身体，累计回报仍跨回合继续相加；与训练的 terminal mask 不一致。
- 诊断遗漏切换奖励和真实动作变化惩罚，转向命令也与训练不同。
- 标为 RMSE 的量实际是残差标准差，遗漏系统偏差；标为 R² 的方差比也不等于一般的 `1-SSE/SST`。
- 两次随机 rollout、每个起点只有两个样本，不足以可靠分离条件回报噪声和数值非确定性。

因此对话中的 `value_r2=-70.868` 不能用来宣布价值网崩坏，也不能经口头换算变成 80–97% 的解释率。目标标准差 15–25 在该输出中没有被测量；即使暂用这些假定数，MSE 80–100 对应的 `1-MSE/Var` 范围也约为 56–87%，并非所宣称的范围。

### 2.3 γλ 的有效追踪长度不是价值目标的总回报尺度

训练实际使用：`delta = r + gamma * V_next - V`，`GAE = delta + gamma * lambda * GAE_next`，`returns = GAE + V`，并包含终止掩码。λ 控制 TD 残差如何累积，不意味着价值目标只能有约 17 步奖励的尺度。

**解析反例，不是仿真成绩**：无终止、恒定奖励 2、γ=0.99、准确价值 V=200。此时 TD 残差和 GAE 都为零，λ=0.95 下的价值目标仍是 200。128 步不带 bootstrap 的截断 MC 回报则约为 144.75。

算式核对保存在 `runs/yumi_obs50/review_20260921/analytical_checks.json`。因此“GAE 只有 17 步，所以预测 91.5 合理”的论证不成立。

### 2.4 已补观测，不等于已证明补观测改善性能

归档工具输出的张量审计是 `best_vs_source.max_tensor_abs_diff=0.0`。它直接否定了这次 best 的分数差来自策略学习，也否定了 Cline 提案的“sensor 补丁带来 +27%”结论。

但它没有否定新增观测的潜在价值：新增编码列从零开始，仍需有效优化才能利用。缺少速度/高度直接输入是代码事实；把它称为唯一根因或认为少量短跑必能证实，也过强。此前观测与膝门控同时变化，因果归属更需谨慎。

### 2.5 同权重审计有效，分数的比较仍需统一

0.869 是含姿态项的 `combined`，约 0.42 是纯 `score`，二者不能直接相减。身高约 0.90 时姿态加项约 0.385。判定没有学习增益的强证据是张量相同，而不是这两个不同口径数值的差。

斜率也不能单独作为成功门槛：`vx = cmd - 0.30` 的斜率恰好是 1，但每档都慢 0.30 m/s。应同时报告各档绝对误差、截距、存活、漂移和步态形态。

## 3. 再训前的最小工程前置

### A. 把 50 维试验接到真实验收路径

训练器已经按检查点识别维度；但 `app/evaluate_full.py:81` 和 `app/studio_server.py:126` 仍构造默认 47 维策略，`app/sim.py:102` 仍返回 47 维观测。50 维模型当前不能直接走完整的主线验收与展示路径。

另外，GPU 环境的时钟为 0.8 s，native 路径为 1.0 s，现有 `physics_interface` 未把这项纳入契约。对于直立世系，原始扫频数据已经说明时钟会改变输出速度。不能把“换时钟提速”与“同一模型训练/部署使用同一契约”混为一谈：前者仍待研究，后者是必要的兼容性工作。

建议只为新实验显式记录并贯通观测布局、尺度、home、时钟周期和动作接口。保留原 47 维检查点与历史验收条件，不能用一次全局时钟替换改写历史基线。

### B. 完成同权重保护和模型比较协议

`app/ppo_yumi.py:226` 只在启动时检查同权重，且会用新单次评估重写门槛。第 449 行训练中候选分支未检查身份。冻结策略只训价值网时，仍可能因两次有利评估而把同一权重当成新最佳。

本轮通过提取实际 AST 分支并使用占位模型做了 CPU 路径检查，确认该候选分支在不验证模型身份的情况下能够调用保存。这不是一次模型性能实验。

建议区分“策略内容身份”和“含元数据的文件 SHA”。同策略的复测用于更新评估分布，不记录为一次策略改进。真正候选与基线用相同初态组、相同条件成对比较；至少多个独立重复块，并保留原始结果和不确定性。固定两次均值加 0.03 不是自动获得统计保障，反复筛选仍会偏向偶然高值。

### C. 诊断复用训练数据，避免维护第二套奖励

从训练的实际 rollout 导出小型数值批次：`obs_t`、action、reward、done、old_value、bootstrap、GAE 与 value target。无需保存全脑激活，也无需重做一份近似奖励函数。

同状态匹配后计算 MSE、RMSE、预测偏差、目标方差、解释方差，并按命令档、存活/终止拆分。补充按完整轨迹或环境划分的留出检查，避免相邻时间点随机拆分造成过于乐观的拟合结论。先检验能否拟合固定数据，再讨论在线目标漂移；不据高 MSE 直接换网络。

未提交的“双侧价值门”也未严格实现两个完整五期窗口：初始历史不足五期便可计数，预算边界仅检查单个滑动均值。若保留，应明确它只是工程停止规则，不是证实或否定科学假说的判据。

## 5. 推荐的一次有限实验

以下是建议预算与设计，不是已获授权的执行命令，也不是收敛时间承诺。

### 阶段 0：离线前置

完成第 3 节的接口、同权重筛选和诊断修正，补小型回归检查。尤其确认 50 维检查点能进入 native 验收；旧检查点的表现和引用保持可追溯。

### 阶段 1：冻结基线与采样校准

- 沿用直立 50 维基线、正确的 tall 身体接口，不重新训练全脑。
- 在固定的 0.35/0.50/0.65 m/s 命令集上重复测量确定性动作表现；另测当前 std=0.08 下的采样表现。两者分别报告，不能混算。
- 采集少量实际训练 rollout，做同口径 value 诊断。若随机动作明显破坏平衡，而确定性动作稳定，优先定位探索分布的影响，不能仅怪价值网。
- 记录新增三列编码权重的变化，以及固定其余输入时，速度/高度小扰动引起的动作变化。若新信息尚未被策略使用，不能用最终分数不升就宣布补观测无效。
- 记录每个优化器参数组学习率。现有日志 `lr` 只显示第一组，在 freeze-brain 配方下是 neuron_bias 的 0.1 倍组，不是读出层主学习率。

### 阶段 2：验证“策略更新是否有益”

- A 为不更新 actor 的基线；B 从同一策略、配套状态和相同实验条件进行短程 actor/critic 更新。
- 维持已选定的直立、50 维、freeze-brain 配方。此轮不同时增加 epochs、改奖励、改时钟和扩环境数。
- 为 B 预先限定更新数和样本数，在固定检查点上成对复测；记录采样数与墙钟，不只看某一瞬时最佳分数。
- 以逐速度档的跟踪误差改善、存活和姿态不退化为进展证据；同时观察足底滑移与有效摆动。斜率只作辅助指标。
- 若只出现分数偶然峰值，结论是本轮未见可靠改善。若预算不足以分辨差异，结论是不确定，不自动解释为路线失败。

建议第一批云端验证采用 **总有卡墙钟上限 60 分钟**，包含加载、采样、更新、验收及等待，到时报告结果，不自动续时。按用户此前报价 1.88 元/小时，对应实例时间约 1.88 元，存储等另计；不是当前平台价格核验。也不能把纯训练内核耗时当账单。启动前检查实际 RAM/VRAM 余量，不与额外 GPU 诊断并发；若资源不够，缩小试验或停止，不沿用“显卡有 24 GB 所以安全”的假设。

## 6. 用结果决定后续，不提前宣布唯一道路

1. **策略能稳定改进，但仍高频拖步**：下一项才改步态目标。用连续有效摆动、足底滑移和接触稳定性区分迈步与抖动；新增塑形只做一个变量，保留独立形态验收。不要把“最低踝”直接称为已测得的承重腿，也不要只增加触地计数奖励。
2. **固定数据的 critic 拟合或留出表现明显差**：再分辨尺度、输入和容量。回报归一化或更大 value 网络是候选，不是仅凭 raw MSE 的必然修复。
3. **critic 诊断合理，但连接组策略反复退步**：引入同身体、同观测/动作接口的普通小策略对照，判断问题主要在奖励/物理任务还是连接组优化。它是诊断对照，不替换最终果蝇连接组控制路径；计算和样本预算均需报告。
4. **对照策略形成有效步态**：可以将其作为专用 Yumi 教师，再蒸馏到完整连接组并做 DAgger。教师只参与训练，最终推理仍走感觉编码→连接组→12 关节，明确记录训练出处。现成 G1 教师迁移失败并没有否定这条路线。

目前不优先做：重新训练全部连接增益、上肢解锁、从头训练整个连接组、脉冲神经元/STDP/多巴胺重构、直接用 f(cmd) 作为速度旋钮。它们会增加变量，尚不能回答当前更新为何不产生可靠收益。

## 7. 需要定稿的方向

我的建议是 **“保持直立世系，完成最小校准，再做一次限时小对照”**。这承接此前选择，同时为错误推断和低收益训练设下明确边界。

若用户更看重尽快得到自然步态而不是继续解释当前 PPO 的失败机制，则可以将“专用 Yumi 教师/参考步态训练”提前为下一阶段；但需要明确这是训练方法的变化，不能把当前拖步验收当成该目标已完成。
