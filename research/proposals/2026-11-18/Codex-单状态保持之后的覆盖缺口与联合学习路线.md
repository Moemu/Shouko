## 2. 为什么仍没有完整任务突破

### 2.1 近场策略没有继承原接近能力，谈不上先学会后遗忘

六个近场 run 均记录 `resume_kind=random_initialization`，`source_checkpoint_sha256=null`。`ppo_holding_goal.py` 创建新 MLP；`ppo_goal.py` 当前还明确拒绝 local 模式的 `resume`。

因此，原 iid_zero 策略负责产生一个物理状态，但它的 actor 没有迁入近场训练。**物理状态继承，不等于控制策略继承。**

后续两米回归，是让一个只学过近场保持的新策略，从未训练过的远端起点自行发现推进。没有接近能力可供保留，也没有证据表明发生了灾难性遗忘。

这是本轮范围内的已确认事实，不是实现缺陷。本轮原本就是条件性近场机制验证。只是它的成功不能自动拼成完整移动能力。

来源：[近场入口](../../../app/ppo_holding_goal.py)、[训练初始化](../../../app/ppo_goal.py)、六个 `learning/<group>_<seed>/summary.json`。

本次检查六个 run 保存的首轮、第二轮和最终轮 rollout，共 18,432 个观测样本。距离范围为 **0.144422～0.305373 米**；距目标至少 1 米的样本数为 **0**。剩余时间字段最大为 0.42，对应原回合剩余 2.1 秒。

**判断：**当前最直接的瓶颈是训练没有连接远场与近场。尚不需要用网络容量不足、连接组不适合或 GPU 不够来解释。

### 2.3 当前成功门能检验保持，却难以检验新增能力

唯一课程状态来自 `1402_145`，即原 iid_zero/1402 的第 2.9 秒。原策略继续会失败，但 zero、hold_angles、damping 三个探针都能成功。

随后随机权重的确定性均值策略也全部成功，约在原回合 4.42 秒完成停留。初始输出接近零，行为与 zero 探针相容。身体进入该状态后，减少原策略的后续驱动就足以完成一次停留。

这并不意味着任何状态都可被动停住。九个分叉中只有这一份阳性；它是一个经筛选的局部有利状态。三个随机训练种子只能检验该状态下的优化重复性，不能代表三种身体来源。

下一轮若仍以“最终在该状态通过”为主要晋升门，初始就过门，难以区分训练收益。应将其保留为回归项，把新进展定义在更早的完整状态或原两米起点上。

来源：`diagnostic/summary.json → positive_forks/probes`、`learning/summary.json → runs[].initial/final`。

### 2.4 塑形按设计重排学习信号，没有填补接近状态缺口

当前处理臂使用：

`Phi(s) = 0.5 × dwell_fraction(s)`

`F(s,s') = gamma × Phi(s') − Phi(s)`

真实终点强制 `Phi=0`。从 `dwell=0` 的起点出发，对完整有限回合有：

`sum(gamma^t × F_t) = −Phi(s0) + gamma^T × Phi(sT) = 0`。

本次从三个处理臂的连续首两轮 rollout 复算，共 48 个完整回合。折扣塑形和的最大绝对残差约 **9.41e-8**，与清算设计一致。

因此，它不是在原任务之外持续增加一份“停住奖金”。它可以把信息提前到合格停留过程中，影响有限样本下的优势估计和优化；但完整回报排序按设计保持不变。这个原则见[势函数塑形原论文](https://aima.cs.berkeley.edu/~russell/papers/icml99-shaping.pdf)。

此外，尚未同时满足距离和速度资格时，dwell 为 0，相邻两步的塑形项也为 0。它没有提供远场推进信号，也没有在进入资格前直接奖励提前减速。把它放进一个初始就能保持的状态，不是检验所有近场塑形方法的充分实验。

**不能推出：**“塑形完全没有梯度”“所有塑形均无用”“以后必须取消所有塑形”。能推出的只是：本轮这项额外机制不是达到该确定性保持门的必要条件。

来源：[dwell_potential_reward](../../../app/braking_task.py)、处理臂 `rollout_1.npz`、`rollout_2.npz`。上述恒等式适用于完成且终点清算的回合，不把半个 rollout 的和当作完整回合。

### C1：同一个接近 actor，两种训练起点覆盖

仅当 C0 仍支持单状态局部能力，且没有新增工程或安全阻塞时，建议下面的对照。目的只比较起点覆盖，不同时搜索奖励、网络和探索算法。

三个来源 actor 固定为前轮完整的 `iid_zero/1401、1402、1403`，不只选最接近目标的 1402。每个来源各复制两份。critic 在新有限任务下重新初始化，同一来源的两臂逐元素一致；Adam 状态新建，不把旧截断 critic 的含义直接带入。

| 实验臂 | 初始 actor | 固定重置比例 |
|---|---|---|
| N：近场单状态 | 对应原接近 actor | 100% `1402_145` |
| M：覆盖接近过程 | 同一原接近 actor | 50% 原两米起点；25% 中间分叉；25% `1402_145` |

中间分叉使用已冻结的三来源 2.0、2.5 秒状态，按预定均匀轮换分配。每次重置保留该状态原目标、elapsed 和剩余期限。两臂都不读取脚本动作标签；M 不在运行中切换控制器，全程由同一个 actor 输出动作。

建议每臂每来源 262,144 次转换，共 1,572,864 次；训练进程累计上限 45 分钟，总墙钟上限 2 小时。样本或时间上限先到即停止，不补未完成单元。

共同设置建议：rho=0、初始 std=0.15、不加 dwell 势函数、沿用 gamma/lambda 与 PPO 其余设置。**训练功系数暂取 0，公共评估仍取 0.001。** 这是运动发现阶段的候选取舍，不是已经验证的最优奖励。

选择零训练功系数，是为了避免把原高耗功接近动作直接压回静止。但它有代价：训练可能不安全或更加低效。每个 run 仍须严格遵守原警戒线；任何中止都保留，不由另一个功系数替补。若用户优先要求效率，应另行定稿成本路线，不把两项目标混入本对照。

近场能力在 std=0.15 下已有经验；接近 actor 在此探索幅度下尚无采样安全证明。正式训练前仅做固定短冒烟确认合同和安全，不按冒烟回报搜索 std。失败则停止该训练包并报告，不边试边选择。

这个对照能回答：“在相同接近初始化和训练设置下，保留原起点是否有助于获得完整到达？”它不能单独回答热启动是否优于随机初始化，也不能将任何收益唯一归因于状态距离；姿态、速度和剩余时间都随状态池变化。

每个来源的初始和预定最终 actor，都在原自然倒伏两米有限任务上做 native/CUDA 确定性评估。两个后端都安全完成原停留，才算该来源通过。组门为至少 2/3 来源通过。

还需保留 `1402_145` 的近场回归：同样至少 2/3 来源通过。报告公共回报和机械功；能力门通过不自动表示效率合格，更不表示可发行。

| C1 结果 | 可支持的判断 |
|---|---|
| M 两米门和近场门均通过，N 两米门未通过 | 支持保留原起点的联合学习；再做新状态和方向验证 |
| 两臂都通过 | 更简单的 N 也足够，不能声称混合覆盖必要 |
| 近场通过，两米均失败 | 衔接问题仍未解决；检查原起点是否真正获得有效更新，不追加相同训练 |

## 5. 需要防止再次出现的解释偏差

- **初始即通过，不等于训练无价值。** 可以研究带噪稳定性，但必须给出固定噪声、冻结权重的相应指标。
- **保持成功，不等于接近过程有训练信号。** 下一阶段日志应按原起点、中间状态、近场分别记录到达、回退和样本比例。
- **奖励清算为零，不等于优化过程完全相同。** 势函数可能影响信用分配；本轮只是没证明其必要性。
- **两米回归失败，不等于容量或算法不可行。** 先确认训练有覆盖该过程，才讨论扩大模型或更换 PPO。
- **同一源轨迹的多个帧，不是多个独立来源。** 既有九状态只能用作开发诊断；最终需另设新的来源与方向。

实现上，当前 local 训练器拒绝 resume，近场入口只接受固定单状态。新路线若定稿，需要显式的 actor 初始化和状态池合同，记录来源权重及状态哈希。不能用伪造旧 reset 哈希或直接把近场 checkpoint 塞进旧加载器绕过约束。

保持旧 v1、旧近场和生产路径。新实验只扩展必要入口，不为本轮顺便建立通用课程框架。未获得新证据前，不改身体、力矩、动作维度或连接组核心。

## 6. 本次复核方法

文中速度和初态指标由保存的 qpos/qvel 经原生 MuJoCo 前向计算得到，没有执行物理积分。样本覆盖、到达比例和势函数残差直接读取原始数组，不重新训练。

下列命令从仓库根目录只读复算保存窗口的覆盖、训练到达比例和塑形清算。它依赖本机已有归档；公开复训入口见 [TRAINING.md](../../../docs/TRAINING.md)。

```powershell
@'
import json
from pathlib import Path
import numpy as np

root = Path('runs/goal_braking_20261117/learning')
for group in ('baseline', 'potential'):
    early, late, distances = np.zeros(2), np.zeros(2), []
    for seed in (1501, 1502, 1503):
        folder = root / f'{group}_{seed}'
```
