# 门口保持之后：接近缺口与保持范围

日期：2026-11-18。作者：DeepSeek（本代理）。状态：提案，未执行；本稿不改代码、权重、任务接口或远端资源。

**独立性声明。** 本稿读过 2026-11-18 Codex 提案的前 40 行与 `research/proposals/README.md` 索引摘要，未读其余 11-18 提案正文；D/L/T 的核验由本稿独立完成。Codex 已指出“物理状态继承、控制策略未继承”，本稿用原始数据进一步确认，并在其覆盖缺口判断上补充“阳性状态在门口、初始策略≈零动作”的证据。**不是盲评。**

## 结论

本轮证明的不是“策略学会制动”，而是**一个距目标约 0.305 米、零动作或阻尼即可被动停住的状态可以保持**。近场训练从随机初始化开始，没有继承原接近策略；初始策略（随机权重、确定性均值）已经 3/3 通过该状态。两米任务 0/3 的原因是任务分布里没有“接近”阶段，不是身体不能推进。

建议下一步先测两件事：**保持技能的有效范围**（多远、多快还能停住）和**旧接近策略的接近边界**（旧 `iid_zero` 还能不能从两米接近）。两者都清楚后再做“接近—制动—保持”的联合课程；不继续在单状态上加预算，也不把保持势函数当成必要修复。

## 一、核验事实

### 1.1 D：唯一阳性是门口状态，且是被动稳定

`diagnostic/summary.json` 的 `positive_forks` 只有 `1402_145`，来自 `iid_zero/1402` 原回合 2.9 秒。该状态距原目标约 **0.305 米**（由近场初始评估 `net_progress 0.094317 + final_distance 0.211056` 反推），半径 0.3 米，差约 5 毫米。

同一状态的六种续接：

| 模式 | 最终距离（米） | 最终水平速度（米/秒） | 功（J） | 结果 |
|---|---:|---:|---:|---|
| 继续原策略 | 1.275339 | 1.207806 | 2,869.97 | 超时 |
| raw 动作归零 | 0.209211 | 0.028931 | 53.35 | 完成 1 秒停留 |
| 固定分叉关节角 | 0.251342 | 0.073485 | 38.17 | 完成 1 秒停留 |
| 阻尼为主 | 0.187802 | 0.000548 | 26.14 | 完成 1 秒停留 |
| 目标 y+0.2 继续原策略 | 0.872304 | 0.928382 | 2,767.27 | 超时 |
| 目标 y−0.2 继续原策略 | 1.150075 | 0.941317 | 2,835.02 | 超时 |

原策略继续会从 0.305 米冲到 1.275 米；零动作、固定角度、阻尼都能停住。**这是该姿态下的物理被动稳定，不是策略学会的制动。** 目标方向一变，原策略同样冲出，说明它没有目标条件的保持能力。

其余 8 个 fork（含另外两个 2.9 秒状态）没有原目标下的完整停留阳性。九份策略的 46,080 次采样转换只找到这一个门口状态。

### 1.2 L：初始策略已经通过，训练只是保留

六个近场 run 全部为 `resume_kind=random_initialization`、`source_checkpoint_sha256=null`（`learning/*/summary.json`）。`app/ppo_holding_goal.py:17` 只调用 `train(..., local=...)`，没有 `resume` 参数；`app/ppo_goal.py` 也拒绝 local 模式的 resume。**物理状态从旧策略继承，控制策略没有。**

近场初始与最终评估：

| 组 | 种子 | 初始净进展（米） | 最终净进展（米） | 初始功（J） | 最终功（J） |
|---|---:|---:|---:|---:|---:|
| baseline | 1501 | 0.094317 | 0.110617 | 53.15 | 69.72 |
| baseline | 1502 | 0.094263 | 0.133870 | 52.59 | 65.93 |
| baseline | 1503 | 0.094932 | 0.155445 | 53.57 | 68.38 |
| potential | 1501 | 0.094317 | 0.111720 | 53.15 | 71.75 |

六组初始与最终都通过，最大连续停留 1.0 秒，结束原因均为 `complete`。初始策略的功 52.59–53.57 J，与 D 的 zero 探针 53.35 J 接近，说明**随机初始策略的确定性均值≈零动作**；它推进约 0.094 米进圈并停留 1 秒，主要是该姿态的自然滑动。训练后的功升到 61.89–71.75 J，近场表现略好，但没有创造“从远处接近”的能力。

训练内到达次数很高：baseline 3,386 / 3,302 / 3,409，potential 3,014 / 3,476 / 3,309。任务从门口开始，到达是常态。

### 1.3 T：原状态几乎静止，训练后反而后退

T 的 18 条只读轨迹全部安全完成、最大连续停留 0。native 结果：

| 组 | 种子 | 净进展（米） | 最终距离（米） | 功（J） |
|---|---:|---:|---:|---:|
| initial | 1501/1502/1503 | +0.000088 / +0.000089 / +0.000114 | 1.99991 / 1.99991 / 1.99989 | 0.0331 / 0.0265 / 0.0420 |
| baseline | 1501/1502/1503 | −0.013391 / −0.008286 / −0.014034 | 2.01339 / 2.00829 / 2.01403 | 15.92 / 16.89 / 17.42 |
| potential | 1501/1502/1503 | −0.006772 / −0.003180 / −0.014171 | 2.00677 / 2.00318 / 2.01417 | 25.53 / 16.03 / 18.68 |

初始策略在原状态几乎完全不动（0.033 J），速度约 3e-6–6e-6 米/秒；训练后的策略开始耗功 16–25 J，但净进展为负，方向不是目标。**近场训练让策略离开了静止状态，却没有产生接近。**

独立核验通过：条件 log-prob 最大误差 1.931e-5、价值 4.769e-7、奖励 7.451e-9、GAE 5.302e-7；54 条轨迹的质心与速度重算误差为 0。

## 二、为什么仍没有显著进展

### 2.1 任务从门口开始，不是从远处接近

阳性状态距目标 0.305 米，只差 5 毫米进半径。近场任务的“成功”只需要滑进半径并停住 1 秒；它没有要求从 2 米、1 米或 0.5 米接近。D 的其余 8 个 fork 没有阳性，说明当前菜单连“从 1 米左右制动”都没有覆盖到。

### 2.2 保持是被动稳定，不是策略制动

零动作、固定关节角和阻尼都能完成停留，原策略继续反而冲出。这个状态的几何/接触本来就容易停住。把它称为“策略学会保持”会高估结果；它最多证明“这个姿态下存在被动保持”。

### 2.3 训练没有继承接近策略

六个 run 全部随机初始化。旧 `iid_zero` 在原任务有早期接近（局部因子净进展 0.498 米），但它的 actor 没有进入近场训练。**没有接近能力可供保留，也没有证据表明发生了遗忘。** 两米回归是让一个只学过门口保持的新策略，从它没见过的远端起点自行发现推进。

### 2.4 原状态静止，训练信号只有保持

原自然倒伏状态是稳定的：初始策略 5 秒只动 0.0001 米、耗 0.033 J。要到达 2 米目标，需要主动推进约 1.7 米。近场训练的状态分布只有门口一个点，奖励只鼓励进入半径和停留；策略没有理由产生“从 2 米推进”的动作。训练后策略在原状态耗功 16–25 J 但没有净进展，说明它学到了一些动作，却没有方向。

### 2.5 评估没有区分“保持”与“接近”

近场评估从 0.305 米开始，初始策略已过；它不能区分“已经接近后保持”和“学会接近”。原两米评估只在 T 里做只读回归，没有作为训练任务或训练中的验证分布。

### 2.6 覆盖限制

- 只有一个近场状态、一个方向、一个自然倒伏初态。
- 2×2、单状态和多状态都不是独立身体来源。
- 近场训练内到达次数不能当成两米任务到达。

## 三、可能方向

### 阶段 0：保持范围与接近边界（零训练，先做）

**H1 保持范围探针。** 从已保存的 D 分叉或原轨迹中，取目标距离 0.3、0.5、1.0、2.0 米、水平速度约 0、0.3、0.6 米/秒的状态；每个状态用四种控制续 2 秒：零动作、阻尼为主、旧 `iid_zero/1402` 策略、L 最终策略。记录最终距离、最大连续停留、半径内速度、功。

判据：若 0.5 米、0.3 米/秒以上没有任何控制能完成 1 秒停留，则保持技能只在门口有效，先扩展制动/状态覆盖，不进入联合训练。若 0.5 米、0.3 米/秒仍能停住，保持范围足够，进入 J。

**H2 接近能力对照。** 用旧 `iid_zero/1402` 最终权重、L `baseline/1501` 最终权重、L 初始权重，从原自然倒伏状态（T 的同一 `screen/reset.npz`）各跑 5 秒，native/CUDA 各一次。记录净进展、3–5 秒进展、最近距离、功。

判据：旧 `iid_zero` 净进展 ≥0.3 米且 3–5 秒进展不继续回退，说明接近能力存在，J1 热启动有依据；若旧 `iid_zero` 也 <0.1 米，说明接近能力本身不足，先修接近任务/奖励，不进入联合训练。

**H3 目标条件响应。** 在 0.5 米和 1.0 米状态，把目标 y 移 ±0.2 米，测旧 `iid_zero` 与 L 策略的动作/位移响应。D 只在 0.305 米测过，且原策略直接冲出；扩展到更远状态，判断目标条件是否只在近场失效。

阶段 0 只读，不更新权重，预算 30–45 分钟。

### 阶段 1：接近—制动—保持联合课程（有界）

只在 H1/H2 给出可用范围时执行。

**J1 热启动 + 多起点。** 用旧 `iid_zero/1402` 的 actor 初始化，任务从 2 米、1 米、0.5 米三档起点开始，目标仍是 +x 2 米；奖励 = 距离进展 + 到达奖励 + 有界 dwell 势函数 − 功成本。三配对种子，每种子 262,144 次转换。

**J2 随机初始化 + 多起点。** 同一任务、同一多起点分布，随机初始化；三配对种子。

判据：在两米原起点上，至少 2/3 种子完成一次 1 秒停留，且 H1 的保持范围不退化。J1 与 J2 同预算比较：J1 明显更好支持“接近策略继承”；两者都失败说明任务、奖励或课程仍不够。

### 阶段 2：原任务回归与延长（有条件）

仅在 J1 或 J2 通过阶段 1 判据时执行。冻结配置，三个新种子，各 1,048,576 次转换；训前封存新的目标/起点序列。判据沿用原任务到达与停留门；不按留出调参。

### 阶段 3：身体或任务变更（需用户定稿）

候选：增加保持状态覆盖、改接触参数、加接触观测、放宽目标距离或时间。任何身体或观测接口变更都会改变合同哈希并作废现有检查点，需要重新验证。本阶段不自动执行。

## 四、预算与分支

阶段 0 约 30–45 分钟 CPU/GPU 只读。阶段 1 共 6 个 run × 262,144 次转换，按上一轮每 run 约 4.2 分钟训练加评估约 5 分钟计，约 30 分钟；工程实现与核验另计。阶段 2 约 36 分钟。每个阶段单独预登记。

| 观察 | 下一步 |
|---|---|
| H1 0.5 米、0.3 米/秒以上无控制能停住 | 保持范围只在门口；先扩展制动/状态覆盖 |
| H1 0.5 米、0.3 米/秒仍能停住 | 保持范围可用，进入 J |
| H2 旧 `iid_zero` 净进展 ≥0.3 米 | 接近能力存在，J1 热启动优先 |
| H2 旧 `iid_zero` 也 <0.1 米 | 接近能力不足；先修接近任务/奖励 |
| H3 目标方向在 0.5/1.0 米仍无响应 | 目标条件覆盖不足；先扩展目标干预，不联合训练 |
| J1 或 J2 2/3 种子过两米停留门 | 冻结配置，进入阶段 2 |
| J1/J2 都失败 | 路线不确定；交回跨厂商提案 |
| 安全中止、后端相反或预算不足 | 停止并报告，不补样本 |

## 五、不做什么

- 不继续在单状态保持上加预算；L 的 baseline 与 potential 都能过，塑形不是瓶颈。
- 不把零动作/阻尼的被动停留当成策略制动能力。
- 不把 L 的初始通过当成“训练创造了保持”。
- 不用近场状态替代原两米任务验收。
- 不直接把接近控制器与保持控制器拼接而不做联合训练；也不宣称拼接一定失败。
- 不改公共 2 米、30 秒、0.3 米、0.2 米/秒、1 秒停留定义；不改身体、PD、接触或观测接口。
- 不按已看到的固定状态挑“最好”种子。
