## 局部任务与重置

从原 `FreeBody` 直立零位用零动作积分 3 秒，生成一份自然倒伏完整状态，保留实际速度、前次动作、warmstart、外力和时间。生成方法与 D0 zero_fall 相同，命令没有推进模板。保存完整 native integration state，并为 CUDA 显式复制各动态字段；冻结状态及源码哈希后才训练。先验证原生/CUDA 初态观测、重置和短步一致性。

局部任务 ID 为 `fallen_local_goal_v1`。每回合都从同一完整状态开始；目标在重置质心水平位置的世界 +x 方向 2 米处；每回合最多 5 秒、只有一个目标。半径 0.3 米、速度上限 0.2 m/s、连续停留 1 秒、到达奖励 1、10 米场地边界沿用原口径。观测仍为 69 维，动作仍为 18 维，每步 20 ms；剩余时间按本任务的 5 秒归一化。此任务不是原直立开局、随机三目标的正式验收。

训练物理状态出现数值或容量错误则该 run 失败；穿透 >30 mm、关节限位误差 >0.15 rad 则停止该 run，并保留已完成样本及最后有效证据。安全中止不补样本，不算通过。其余预登记 run 可继续，避免丢失其余对照；全阶段无法完成等预算时不能作完整因素归因。

## 四组、分布和预算

| 组 | rho | 训练功系数 |
|---|---:|---:|
| iid_cost | 0 | 0.001 |
| iid_zero | 0 | 0 |
| persistent_cost | 0.9 | 0.001 |
| persistent_zero | 0.9 | 0 |

各组随机初始化种子为 1401、1402、1403。每种子四组 actor、critic、初始 base log_std 和优化器状态一致。初始 base std 固定 0.70：此前正常重力探针已测过该幅度，本轮各组保持相同，不用组间变幅解释结果。它与旧 0.35 基线不同，不能把跨轮差异只归因于低姿态起点。

持续组条件分布为：

`a_raw ~ Normal(rho × a_previous_executed + (1−rho) × actor(obs), sqrt(1−rho²) × clamp(exp(log_std),0.05,1.5))`。

观测已含前次执行动作，不另加未观测噪声状态。物理仍将 raw action 截到 ±8；PPO 保存截断前样本及对应条件 log-prob，更新使用同一条观测中的前次执行动作。rho=0 恢复独立 Normal。均值固定且无截断的稳态下，两组 base std 对应相同动作方差；重置瞬态不保证方差相同。

确定性评估也用该条件均值，而非绕过滤波直接使用 actor 输出。该处理同时改变动作持续性和确定性控制响应；若有效，只能归为此持续控制分布的收益，不能说纯噪声相关性是唯一原因。执行规则、rho、局部任务和 reset SHA-256 均与 checkpoint 绑定；旧任务加载器须拒绝局部权重。

PPO 其余设置沿用：16 世界、每轮 64 步、2 epochs、minibatch 256、actor lr=3e-4、value lr=1e-3、gamma=0.99、lambda=0.95、clip=0.2、entropy=0.001、target_kl=0.02。每 run 256 轮，12 run 共 3,145,728 次转换。等预算指等物理转换，不保证 KL 早停后的 Adam 更新数相同。

按种子分块交错运行；1401 顺序 iid_cost、iid_zero、persistent_cost、persistent_zero；1402 顺序 persistent_cost、persistent_zero、iid_cost、iid_zero；1403 顺序 iid_zero、iid_cost、persistent_zero、persistent_cost。正式运行期间不按中途回报改参数，不挑最佳检查点。只用预定最终权重作主比较。

## 评估、晋升与分支

每种子按 rho 分别评估初始确定性策略；同 rho 的两功系数组初始策略逐元素一致。全部最终权重分别用原生和 CUDA 评估一次，同一完整初态、目标及原功系数 0.001。保存每步完整观测、raw/executed action、COM、qpos/qvel、奖励分量和物理指标。相同确定性回合不复制成多个“独立样本”。

单种子局部进展通过需满足：完整安全回合，净进展 ≥0.25 米，相对本组初始确定性策略改善 ≥0.15 米，1～5 秒进展 ≥0.20 米，3～5 秒进展 ≥0.05 米。若在 5 秒内已按停留规则到达，免除后两段条件，但仍须安全及初始改善。原生与 CUDA 均通过才计入；至少 2/3 训练种子通过才称组通过。最大穿透与限位沿用上述警戒线。

| 实测分支 | 下一步 |
|---|---|
| 至少一组 ≥2/3 种子通过 | 冻结候选；优先通过种子数，再到达数，再后半段进展组均值，完全相同优先 iid_cost、persistent_cost、iid_zero、persistent_zero。进入下一段前预登记原初态恢复课程，不能把本段当完整任务验收 |
| 仅零功组通过，而按公共功系数收益仍差 | 只能支持发现动作，效率取舍未解决；保留四组结果，交回奖励/探索课程路线讨论 |
| 无组通过，但有明确实现缺陷 | 修复确认缺陷，追加受影响范围与预算，不静默覆盖旧 run；若已影响公平比较则停止正式归因 |
| 无组通过，只有一臂单种子阳性、后端相反或机制仍不能区分 | `route_uncertainty_stop`，不盲加样本、不自动改变身体或任务 |
| 预算耗尽或运行条件缺失 | `budget_stop` / `engineering_block`，报告实际转换数和未完成对照 |

若多组完成，将报告配对种子上的探索效应、功系数效应及差中之差，明确样本仅三个，不作统计显著性或唯一根因声明。训练回报、参数更新和均值速度均不单独作为能力证据。

### 不是单一的“没有移动”

`iid_cost` 三个策略在 5 秒内平均只缩短距离约 0.87 mm，基本停留。`persistent_cost` 的三个净进展分别为 0.173490、0.405707、0.095400 米，但第 3 秒以后进展接近 0 或略回退，收益主要来自早期位移。

`iid_zero` 的三个净进展分别为 0.475988、0.724661、0.292911 米，但它们在第 3～5 秒分别远离目标 1.037927、1.022634、1.352851 米。仅看终点净进展会漏掉中后段回退。

种子 1402 的 iid_zero 是最明确的制动/停留失败例子：

- 最近距离为 0.087650 米，发生在第 3.36 秒，已进入 0.3 米目标半径。
- 最近点水平速度为 0.939771 m/s；半径内最小速度仍为 0.463325 m/s，高于 0.2 m/s 上限。
- 20 ms 保存点统计的半径内总时间约 0.86 秒，不是 1 秒连续合格停留；实际最大 dwell fraction 为 0。

这些数字由原生 qpos/qvel 重算质心速度，见 `braking_diagnostic.json`。可以确认该策略能向目标附近运动，但没有完成减速、停留和目标保持。尚不能据此将根因唯一归于折扣、奖励或探索。

### 可作的配对比较与不可作的交互推断
