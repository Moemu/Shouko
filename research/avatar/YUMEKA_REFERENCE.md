## 对当前可视化的建议

1. 下一步优先评估绘制全部 139,662 个有坐标的胞体点，保持稠密轮廓，按活动数据突出局部变化。增加显示数量不会增加网络训练参数。
2. 增加可放大的神经活动视图及旋转观察；先确保本机身体推理与点云同时运行仍达到需要的帧率。
3. 连线另作一层：从真实连接组中选取选中神经元的输入 / 输出连接，或筛选强连接。显示清楚方向与筛选数量，避免所有 2,558 万条边同时遮挡画面。胞体之间的直线只代表连接关系，不代表真实轴突形状。
4. 若展示内部传播，只能使用模型每次前向计算的实际中间活动；当前 API 只提供四步传播后的活动，不能直接生成传播路径作为事实展示。

坐标以 float32 存储约 1.60 MiB，一帧全量活动约 0.53 MiB。容量本身不大；持续传输、JSON 编解码、点重叠和绘制开销仍需实测，不能仅按显存推断帧率。当前尚未实施全量显示。
